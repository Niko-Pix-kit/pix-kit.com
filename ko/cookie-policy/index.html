자동 (브라우저)

쿠키와 이용자의 선택

쿠키 선택을 저장합니다. 언어 저장과 Google Analytics를 통한 이용 현황 측정을 각각 허용할 수 있습니다.

쿠키란 무엇인가요?

쿠키는 브라우저에 저장되는 작은 텍스트 데이터입니다. 선택 사항을 기억하고, 동의한 경우 웹사이트 이용 현황을 측정하는 데 사용합니다.

필수 쿠키: cookie_consent

cookie_consent는 언어와 분석에 대한 선택을 각각 180일 동안 저장합니다. 방문자 고유 식별자는 포함하지 않습니다.

선택 쿠키: site_language

site_language는 언어 저장을 허용한 경우 직접 선택한 언어를 최대 365일 동안 기억합니다.

Google Analytics

동의한 경우 Google Analytics는 페이지 조회 등 사이트 이용을 측정합니다. Google은 기술적 연결 정보와 브라우저 데이터를 받습니다. _ga 및 _ga_Y3KP2PKKS3 쿠키는 브라우저를 구분하고 최대 180일 동안 세션 상태를 유지합니다. Pix-kit은 페이지 조회 설정에서 URL 쿼리와 프래그먼트를 제외하고, 참조 URL을 오리진으로 제한하며, 사이트 태그에서 광고 기능을 비활성화합니다.

쿠키를 거부하거나 차단한 경우

쿠키를 거부하거나 차단해도 사이트를 이용할 수 있습니다. 페이지 주소와 탭 세션으로 언어 선택을 유지할 수 있습니다. 쿠키가 차단되면 탭에 쿠키 선택이 저장될 수도 있습니다. 자동 언어 선택은 브라우저 설정을 사용합니다.

호스팅 및 외부 웹사이트

호스팅 제공업체는 웹사이트를 제공하기 위해 IP 주소를 포함한 기술적 연결 정보를 받습니다. Google Play나 YouTube 등 외부 사이트로 이동하면 해당 사이트의 정책이 적용됩니다. 각 앱의 개인정보 처리방침은 앱 내 데이터 이용을 설명합니다.

선택 변경 또는 삭제

페이지 하단의 환경설정 관리에서 각 선택을 언제든 변경할 수 있습니다. 항목을 끄면 해당 사이트 쿠키가 삭제됩니다. 브라우저에서도 쿠키를 삭제하거나 차단할 수 있습니다.
